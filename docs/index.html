Stop-motion shorts from one line

Tell Codex a story in one sentence and pick a material. It draws the puppets and sets, moves them in code frame by frame, scores the film and opens a review page for your notes. Claude Code with an image model works too.

How it works

Images make it look right. Code makes it move.

The image model never draws a moving picture. It draws sheets; Python cuts them into cells and times them on twos, over a background, with shadows, light and camera.

From one line to a film

  1. It asks everything at onceWhatever your sentence left out (style, story, length, size, narration, title cards) in one set of questions, defaults first. Then it works through to the end.
  2. It plansA story skeleton with seconds per part, beats, a shot list and an image list.
  3. It generates the picturesCharacter sheets, backgrounds, 8-cell action sheets and 2×2 close-up sheets on transparent backgrounds, in one material.
  4. It animates in codeThe sheets are cut into cells and timed on twos or threes, with camera moves, contact shadows, light and grade.
  5. It adds soundAn original score from real instrument samples, foley on every contact, optional narration and subtitles.
  6. You reviewA local review page: pause on any moment and write a note; it fixes every note until you approve.

Review

You review, it revises

When the film is ready, the agent opens a review page in your browser: the film above a strip of its shots.

  1. 1
    Write a note where it happensPause on the moment and press Enter. The time, frame and shot are attached, and a pin marks the note on the strip.
  2. 2
    Send itThe agent works through every note, replies under each one with what it changed, and adds the next version. The page asks you to reload.
  3. 3
    Approve itWhen it looks right, click Approve and the agent delivers the film.
Agent is waiting · 26 min leftTake your time

The top of the page shows whether the agent is waiting for you, for up to 30 minutes. If time runs out, nothing is lost: notes are saved as you write. When you are done, click Send or Approve and tell the agent in the chat.

Install

Add it to Codex

Two commands in Codex. Claude Code works too: one line in the chat.

You need macOS or Linux, ffmpeg, and Python 3.11–3.13 or uv. Codex draws the pictures with its built-in image generation. In Claude Code they come from the Codex CLI on the same machine, or from your own image tool (experimental).

Recommended in Codex: GPT-6.2 Sol or GPT-6.2 Astra, reasoning High or above. GPT-6.1 Sol and GPT-6 Astra work too.

Full install guide: updates, removal, manual install · SKILL.md

  1. Add the plugin
    Codex
    codex plugin marketplace add lemomo-ai/lemo-animi
codex plugin add lemo-animi@lemomo-ai
    Claude Code
    /plugin install lemo-animi --marketplace lemomo-ai/lemo-animi
    Codex: run both in a terminal, then start a new chat. Claude Code: type the line in the chat, then /reload-plugins, and make films in auto mode (Shift+Tab).
  2. Ask for a film
    The first time, it installs the Python environment and the instrument samples (about 1.7 GB) before it asks anything, and starts asking once they check out.
