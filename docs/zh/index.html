一句话，做一支定格动画短片

用一句话跟 Codex 说个故事、挑一种材质：它用自带的生图画出角色和布景，在代码里一格一格地让它们动起来，配好乐，再打开审片台等你写意见。Claude Code 配一个生图模型也能做。

怎么做出来的

图负责好看，代码负责动

生图模型从不画会动的画面，它只画「表」：角色设定、动作表、空背景。Python 把表切成一格一格，一拍二排在背景上，加阴影、光和运镜。

从一句话到一支片

  1. 开工前一次问完你那句话没说到的（风格、故事、时长、画幅、旁白、片头片尾）放在一组问题里，默认项排第一；之后一路做到成片。
  2. 先定方案故事骨架和每段秒数、节拍、镜头表、生图清单。
  3. 生图角色设定、背景、八格动作表、2×2 近景表，透明底，全按同一种材质。
  4. 代码让它动动作表切成一格一格，一拍二或一拍三排时间，加运镜、接触阴影、光和调色。
  5. 配声音真实乐器采样写的原创配乐，每个接触都有拟音；需要的话加旁白和字幕。
  6. 你来审本地审片台：停在哪一刻就在哪写意见，它逐条改完，直到你点通过。

审片

你来审，它来改

片子做好后，agent 会在浏览器里打开审片台：上面是片子，下面是一格一格的胶片。

  1. 1
    在哪一刻就在哪写停在要改的那一刻按回车。时间码、帧号和镜头自动带上，胶片上钉一枚图钉。
  2. 2
    提交agent 逐条去改，在每条意见下回复改了什么，再登记新的一版，页面提示你刷新。
  3. 3
    通过满意了点「通过」，agent 交片。
agent 在等你 · 还剩 26 分钟慢慢看，不着急

页面顶上显示 agent 是不是在等你，最多等 30 分钟。过了时间什么都不会丢：意见边写边存。写完点「提交」或「通过」，再回对话说一声就行。

安装

装进 Codex

Codex 里两条命令。Claude Code 也能用：在对话里输入一句。

需要 macOS 或 Linux、ffmpeg，以及 Python 3.11–3.13 或 uv。Codex 用自带的生图画图；在 Claude Code 里，图由本机的 Codex CLI 来画，也可以接你自己的生图工具（实验功能）。

Codex 里推荐 GPT-6.2 Sol 或 GPT-6.2 Astra，推理强度 High 及以上；GPT-6.1 Sol、GPT-6 Astra 也可以。
